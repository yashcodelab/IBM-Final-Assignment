# IBM-Final-Assignment
📊 Analyzing Historical Stock and Revenue Data — IBM Data Science Project
📘 Overview

This project is part of the IBM Data Science Professional Certificate on Coursera. The goal is to analyze the historical stock performance and revenue trends of Tesla (TSLA) and GameStop (GME) using Python. The project demonstrates data extraction, cleaning, visualization, and dashboard creation using yfinance, web scraping, and plotly.

🧩 Objectives

Extract stock data using Yahoo Finance (yfinance).

Extract revenue data from web sources using BeautifulSoup.

Clean and organize the data into Pandas DataFrames.

Visualize stock prices and revenues over time using a custom plotting function.

Build and interpret interactive plots for Tesla and GameStop.

🧠 Tools & Libraries Used

Python 3

Pandas – Data manipulation and analysis

yfinance – Downloading historical stock data

BeautifulSoup – Web scraping for revenue data

Requests – HTTP requests to fetch webpage data

Plotly – Interactive graphing library for visualizations
